# Content engine

Formats: Reel, image post, text post, poll, carousel. Text post has a workflow so a later plan can use it. Month one does not import any text-only posts.

Each task carries the Page persona, pillar, angle, hook, source brief, script requirements, image instructions, Reel scenes when relevant, caption instructions, engagement question, expected reaction, assignee, reviewer, due time, publish time, asset requirements, publication status and 24-hour, 72-hour and 7-day checkpoints.

Statuses: planned, assigned, in progress, ready for review, changes requested, approved, scheduled, published, metrics due, performance recorded, cancelled.

A finished asset is not a published post. Submission requires the format checklist, the quality checklist, a submission note and an asset reference. Masho cannot approve his own work.

AI help is copyable prompts for an external ChatGPT or image tool. The prompts include the Page bible, hook, tone and originality rules. Phase 1 does not call a paid AI API. Humans edit and review every result.

Quality checks cover UK English, one idea, originality, false testimonials, private material, age-appropriate content, anatomy and type, the opening, captions and format, and disclosure. Weeks 1 and 2 do not carry affiliate links. A later guide bridge must be identifiable as advertising.

Performance math can calculate shares, comments, follows and website visits per 1,000 organic reach. With fewer than 50 recorded posts on a Page, the only recommendation is that the sample is too small. No screen shows fabricated reach or revenue.

If a topic is weak, cancel or replace it. Do not keep producing it only because it is on the calendar.
