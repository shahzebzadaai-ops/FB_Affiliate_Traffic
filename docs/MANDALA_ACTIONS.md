# Mandala actions

The sixty-four actions are seeded from `src/domain/mandala.ts`. Titles match the approved pillar list. Each row stores id, pillar, title, description, success criterion, owner label, priority, status, dependencies, due date, completion date, evidence, measurement, data source, confidence, blocker and last review.

Dependencies are empty until Shahzeb records a real dependency. Owner labels name Shahzeb or Masho as the responsible person. That label is not a claim that the work is done.

Do not mark an action COMPLETED without evidence and a measurement source. The current database has no measurements.
